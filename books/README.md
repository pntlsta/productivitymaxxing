# books/

Put `.epub` files in this folder. Workbench's Library lists them automatically under **From your repo**.

To add a book on GitHub: open this folder, click **Add file → Upload files**, then drag your `.epub` files in and commit.

Click a book in the Library to add it. It downloads into that browser, and its progress, bookmarks and highlights sync through your private data repo. On any other device it downloads again automatically.

Note: if this repo is public, anyone can download the files in this folder.
